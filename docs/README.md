# Project Docs

Bu klasor, proje davranisini agent-okunur ve insan-okunur Markdown notlariyla anlatir. Canli sistemden veri cekmez; repo ile birlikte surumlenen mimari hafizadir.

Obsidian kullanirken vault kokunu repo icindeki `docs/` klasoru olarak ac.

## Nereden baslamali?

1. [[00-agent-orientation]] ile coding agent okuma rotasini sec.
2. [[standards/agent-documentation-rules]] ile dokumantasyon kurallarini oku.
3. [[architecture/README]] ile sistemin nasil calistigini oku.
4. [[decisions/README]] ile kalici karar kayitlarini oku.

## Agent kullanimi

- Uzun tarihce icin `PROGRESS.md` taramadan once ilgili `docs/` notuna bak.
- Eski ayrintili changelog kayitlari `docs/history/progress-archive.md` altindadir; current truth degildir.
- Her yeni kalici not en az bir hub'a veya `Related` bolumune baglanir.
- `.obsidian/` yerel ayardir ve commit edilmez.
