# Agent Orientation

Bu dosya, projeyi ilk kez acan coding agent icin okuma rotasidir. Goreve gore ilgili rotayi izle; tum `PROGRESS.md` gecmisini bastan tarama.

## Once oku

- Genel docs haritasi: [[README]]
- Dokumantasyon kurallari: [[standards/agent-documentation-rules]]
- Mimari notlar: [[architecture/README]]
- Karar kayitlari: [[decisions/README]]
- Tarihce arsivi: [[history/progress-archive]]

## Gorev rotalari

### Kod degisikligi

1. `AGENTS.md`
2. Bu dosya
3. Ilgili mimari veya modul notu
4. Ilgili kaynak/test dosyalari
5. `PROGRESS.md`

### Public API, contract veya veri modeli

1. Ilgili contract/veri modeli notu
2. Ilgili mimari not
3. Etkilenen consumer docs
4. `PROGRESS.md`

### Dokumantasyon degisikligi

1. [[standards/agent-documentation-rules]]
2. Ilgili docs notu
3. `PROGRESS.md`

## Guncelleme kurali

- Davranis degisirse ilgili docs notunu guncelle.
- Kalici mimari karar degisirse `docs/decisions/` altina karar kaydi ekle.
- Anlamli degisiklikte `PROGRESS.md` altina kisa dated changelog ekle.
- Ayrintili tarihce gerekiyorsa [[history/progress-archive]] oku; current truth olarak kullanma.
